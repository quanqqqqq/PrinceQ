# 对话 UI 一致性验收

日期：2026-10-15。

任务 AI 协助与 Agent 助手共用 `ConversationMessage`、`ConversationSystemNotice` 和 `useConversationScroll`。用户消息靠右显示蓝色气泡，助手回复靠左显示浅色气泡；两者使用相同的头像、字号、圆角、留白与消息间距。确定性操作结果使用独立系统通知，较长的执行内容可展开查看。

## 页面验收

`tests/conversation-ui.fixture.html` 并排挂载两个真实组件，API 返回模拟数据。预览确认与失败重试均在该隔离页面执行，没有修改真实任务。

| 场景 | 结果 |
| --- | --- |
| 用户、助手与既有取消结果 | 两个模块使用统一消息样式与明确来源标签 |
| 系统通知详情 | 可展开；不重复展示回复标题及状态徽章 |
| 修改预览确认 | 确认前保留预览按钮；确认后按钮失效并出现系统通知 |
| Enter / Shift+Enter | 分别发送与换行，多行用户内容保留 |
| 发送失败及重新发送 | 错误与重试入口保留；重试替换原消息，没有重复用户气泡 |
| 任务发送中 | 用户气泡立即可见，输入与语音入口保持锁定 |
| 长消息、长链接 | 两个 502px 面板无横向溢出；最新消息距底部均为 0px |
| Agent 助手新回复 | 共用滚动逻辑后，新消息仍跟随到底部 |

另外从隔离健身目标应用入口检查了 Agent 助手和任务 AI 协助的历史会话。实际 Agent 助手滚动视口宽 319px，没有横向溢出；展开长执行详情后，展开控件仍在原来的 y=505px，阅读位置未跳到底部。任务 AI 协助视口宽 671px，历史预览、执行结果和取消通知正常显示，重新打开时位于最新消息。

类型检查、ESLint、生产构建及 30 项消息同步、运行模式和任务语音相关回归通过。本轮未调用真实 Agent 或麦克风。
