# Skill 真实对话场景

分别运行 `npm run test:skills:conversation -- claude` 与 `npm run test:skills:conversation -- codex`。可设置 PWQ_SCENARIO_MODEL 以测试明确选中的模型，PWQ_SCENARIO_REPORT 指定输出报告路径。

每次新建临时 SQLite、习惯目录和助手配置，在独立端口启动后端；不改现有数据。使用已安装 CLI 的正常认证，强制真实模型模式，不回退规则命令。

同一会话按登记 → 查询 → 调整 → 删除推进。每次写意图必须返回单个对应操作的预览；确认前比对业务数据未变，核对对象和字段后才确认测试记录；读回核对名称、说明、目标关联、实际分钟和删除结果。重复确认不产生第二次写入，所属目标保留。临时环境保留报告便于检查，服务自动关闭。

默认 3 小时/天，0.25 天保存 45 分钟，调整为 0.5 天后保存 90 分钟。报告包含真实请求、回答、预览以及逐步检查结果。这个脚本会真实调用模型并消耗用量。
