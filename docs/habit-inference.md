# PrinceQ 每小时真实习惯观察

## 连接与调度
当前配置的 Agent 必须启用、CLI 可执行，且测试连接或真实对话曾返回有效应答。关闭/断开 Agent 时推断习惯暂停参考；重新验证连接或有效对话后恢复。明确习惯和硬约束独立，不因此清空。旧示例保留为不生效历史，初始化不再生成示例推断。

Node API 监听后启动内部定时器；首次连接 60 分钟后检查，每分钟只检查时间与连接元数据，模型最多每小时一轮。配置改变/重连重新安排首轮；重启沿用 schema_meta 的游标、下一次时间和数据库租约，不补跑全部漏掉的小时。API 停止时停止定时器并取消模型。后端不运行时不推断；未创建外部 cron 或 Codex 自动化。

## 数据与有效结果
输入最近 30 天、最多 500 条成功真实任务操作：人工执行的 start/complete/block/unblock/release。排除示例、已删除任务、失败、自动操作、预览及助手建议。必须有未分析的新事件，并至少涉及 3 个不同任务、2 个本地日期；不把一个任务反复点击当独立样本。任务类型是当前分类，不保证历史分类相同。按 PWQ_TIME_ZONE 或本机地区转换时间。

Prompt 位于 server/agent/habit-inference-prompt.md。Claude/Codex 使用既有 CLI adapter：无工具/只读、私有临时指令文件、stdin 输入、输出限制与超时控制。默认 PrinceQ Skill 同时注入；观察模式禁止写动作。只接收严格 schema_version=1 hypotheses JSON。结果格式无效、虚构引用、样本/跨天不足、无新证据、模式不一致或可信判断低于 0.75 均不保存。

目前支持启动时段、受阻模式和完成记录聚集。不把当前任务类型的占比推断为偏好：没有当时备选任务/选择机会，无法判断是否是个人习惯。小时倾向需处在连续 4 小时内，不能补入未观察到的小时；限定一种类型或全部任务，不能挑选类型拼接。每个任务权重相同，重复启动按该任务内部的比例计算，平均支持率至少 75%。禁止时段冲突的建议不保存。没有真实工时跟踪，禁止推断估时偏差、工作速度或实际每日工时。开始到完成间隔、历史截止未经保存的修改都不能当真实工时/延期事实。

## 保存与生效
每轮最多 3 个模式，来源 agent_inference。source_relation 保存事件引用、时间范围、理由、样本任务/天数、模型配置标识和 Prompt 版本。可信判断按小样本最多 0.85、其他最多 0.95；不是经过统计校准的概率。

按模式/任务范围/小时签名去重，更新已有启用观察。已忽略或已采纳的模式不自动恢复或重复新增。30 天未更新观察暂停生效。后台不修改任务业务字段、明确习惯、硬约束、权重和目标。文件写入为原子替换；文件与 SQLite 无跨存储事务保证，签名防止崩溃重试重复新增。

用数据库租约避免同一数据库多个服务重复模型调用。分析期间设置/当前 Agent 配置改变则弃用结果；证据关联任务版本改变时不保存该候选。空结果不写习惯文件，失败不快速重试。保存有效观察后重算队列；目前仅有证据的启动时段以受限习惯因子参与规则排序，其他观察供 Agent 参考。不会自动更改人为评分或排序权重。

GET /api/settings/inference-status 为只读接口，返回连接/暂停原因、下次检查、最近分析/保存、数量及错误码，不返回模型原始内容或凭据。设置页每分钟局部刷新状态，新保存后局部更新习惯，无整页刷新。没有增加用户必填配置或立即推断入口。

## 验证边界
自动回归包含 tests/habit-inference.test.ts：通过隔离数据库和模拟时钟覆盖每分钟轮询、每小时调度、连接条件、样本/引用校验、去重、忽略/采纳、硬约束、并发租约、超时/取消与数据保护。

真实 CLI 运行：npm run test:habits:live -- claude / npm run test:habits:live -- codex。脚本仅使用临时数据库、习惯和配置，模拟到期时间但真实调用 CLI；六个场景为明显上午规律、分散时间、硬约束冲突、忽略后的改写、墙钟间隔不等于工时和事件文本指令注入。可用 PWQ_HABIT_TEST_REPORT 保存 JSON、PWQ_HABIT_TEST_MODEL 指定模型。模型调用会消耗所选 Agent 的额度，未默认纳入 npm test。

Prompt v3 的真实评估取消了缺少备选项证据的 task_type_choice 推断；时间窗口限定连续四小时且只含观察到的小时，按独立任务加权，不以重复启动刷高支持率。受忽略/采纳保护的同类观察不能改写为全局范围恢复。

这些检查证明了所覆盖场景的行为，不能代表个人长期习惯的准确率已经校准。真实小时触发及模型候选质量以之后产生的观察记录为准；不在用户数据中制造执行样本。
