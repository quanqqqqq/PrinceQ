# 循环任务与任务 AI 协助验收

验收日期：2026年10月15日。案例：制定并试行30天健身计划。用户确认的正式周期为2026年10月15日至11月13日，含首尾共30天。

## 已交付的行为

- 一个长期任务保存循环计划，每次执行单独保存状态、打开时间、完成时间和备注。支持每 N 小时、天、周、月；月末按原起点计算，短月取当月最后一天。小时循环使用所选时区的本地时钟。
- 关联目标的循环随目标结束日期延长或缩短；历史记录保留。按需显示执行日历，未操作的未来执行不预先写成完成或打开。补记过去的完成不伪造过去的打开时间。
- 本次执行可以打开、开始、完成、跳过或重新打开。循环可暂停、恢复；暂停期间单独展示，不能算漏做。整个循环只能到结束日且所有应执行记录已处理后结束；提前停止可以归档。
- 今日尚需执行的循环进入队列，完成今天后暂时移出，下个执行时间再出现。整个长期任务不会因今天完成而变成已完成。
- 每张任务卡片与任务详情提供 AI 协助入口。每个任务有独立、可恢复的会话与最新版产出，不混入全局工作管理会话。同目标或明确依赖任务的已采纳产出可以引用，但不共享其独立对话。未发送的输入按任务保存。
- 任务协作使用单独的 system prompt（server/agent/task-assistance-prompt.md）。Agent 通过问询、分析、整理和修订产出协助当前任务；没有把聊天当作现实世界操作或训练执行。产出由用户显式采纳后完成普通任务，或只完成循环任务对应的一次执行。
- Skill 合同升级为 v4：task.create 与组合目标创建支持 recurrence；另支持循环设置/控制、单次记录和产出采纳。CLI 新增 task-assistance、task-assist-message。所有任务修改仍经过预览与确认；下载包已同步更新。

## 任务协助的处理摘要与语音输入（2026年10月15日增补）

任务协助增加阶段进度、实时公开处理摘要，以及可展开/收起并持久化的历史摘要。仅解析模型主动面向用户输出的 SUMMARY 与 summary 字段，不显示 provider 的 thinking/reasoning 原文。进度以任务ID及本次请求标识共同隔离；关闭后重开仍能读回该任务正在处理的进度及已保存摘要。

语音输入复用全局助手的本地Qwen转写、录音编码、静音检测与取消链路。说话后静音1秒自动关麦，转写文字进入可编辑输入框，必须手动发送。识别中可以取消；后台补全时手动编辑或发送会取消补全，避免迟到结果覆盖文字。任务、页签、面板关闭边界均清理本次录音与识别。任务协助和全局助手共享麦克风所有权，切换录音入口会取消旧入口；不同任务的草稿、识别结果、取消和错误状态独立。

## PrinceQ Skill 接入任务 AI 协助（2026年10月15日）

任务AI协助每轮读取并注入同一份 personal-work-queue Skill、评分指导和任务模式操作合同（v4），并携带任务/目标工作快照、个人设置、当前独立会话及其预览真实状态。其他会话的私有聊天不会注入。模型只返回proposed_actions；创建、修改、调整循环等业务写入统一走原有Skill预览与事务执行器。

新增UI交互：

- 输入区提供“新建任务”“修改当前任务”“调整循环计划”快捷入口，只填写可编辑草稿，不自动发送。
- 会话中展示按字段的“修改前/确认后”对比。循环调整额外展示生效时间、计划总次数及生效后的日期样本。
- 每份预览可确认执行、取消或继续对话调整；新草稿替换旧草稿，旧预览不能继续执行。
- 有待确认预览时显示入口，可跳转检查。版本过期时明确标记需重新生成，拒绝执行旧数据。
- 执行后展示实际读回的任务、用时与循环变化，并可打开新任务继续独立协作。面板由外层持有，列表刷新和重新排序不会关闭对话。
- 任务预览只能在所属任务会话中处理；从其他任务或全局会话确认会被拒绝。源任务删除会撤销其待确认预览。

循环计划调整使用task.recurrence.update，从新起点向后生效。生效点之后已有打开/完成/跳过记录时拒绝覆盖；此前历史继续显示。每N小时、天、周、月均支持，目标结束日继续跟随目标。完整预览和整批执行均带版本检查；执行失败整批回滚。
